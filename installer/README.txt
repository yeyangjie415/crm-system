CRM System v1.0 — 安装说明
================================

系统要求：
  - Windows 10/11 64位
  - 需要安装 Node.js（如未安装，安装包会提示下载）

安装步骤：
  1. 双击运行 CRM-System-Setup-v1.0.exe
  2. 选择安装目录（默认 C:\Program Files\CRM System）
  3. 等待依赖安装和数据库初始化完成
  4. 安装完成后桌面会生成「CRM System」快捷方式

启动方式：
  - 双击桌面「CRM System」快捷方式
  - 浏览器访问 http://localhost:5173
  - 管理员账号：admin / admin123

升级安装：
  - 直接运行新版本安装包，会自动保留数据库
  - 旧版本数据不会丢失

卸载：
  - 开始菜单 → 卸载 CRM System
  - 卸载前会询问是否备份数据库
